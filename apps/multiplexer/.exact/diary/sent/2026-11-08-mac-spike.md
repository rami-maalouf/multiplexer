### Rough

- Finding the macOS commands took a code search. `docs/start-here.md` lists only `web`,
  `ios --run` and `windows --run`. `docs/testing.md` names no macOS verb. The build verb is
  `mac` (from `scripts/help.mjs`), but `agent macos` and `test macos` use `macos`. Cost: about
  10 minutes of reading the CLI source. What would have helped: one line in start-here with
  `mac --run`, `agent macos` and `test macos`, and one spelling for the platform in every verb.
- `verify macos` is refused ("verify: web, ios, windows or android"), so the app's property
  check cannot cover the Mac build.
- The first signed-in drive failed with "op 6/11 `clock data`: unreadable reply: <a log line
  of the native module>". On the Mac, the drive's replies and the app's standard output are
  one stream (`Agent.out` is standard output; `agent-wire.mjs` takes the next line as the
  reply), so a module's `print` is read as a reply. On iOS the same `print` is harmless.
  Cost: about 15 minutes. Workaround: a `moduleLog` helper that writes to standard error, in
  place of every `print` in the module. What would help: the stdio carrier keeps replies on a
  duplicated descriptor and sends descriptor 1 to standard error.
- Every send in a chat ends with the app stopped by SIGTRAP within a second (5 of 5 drives).
  The message is sent first. No crash report, no assertion text in the system log. Under
  lldb the stop is in AppKit, `NSGlassEffectContainerView.layout()`, from the window's display
  cycle, with no Exact frame above `main`. The composer bar holds several glass buttons, and a
  send swaps the send button for the voice button. Removing the send button's exit animation
  did not help. Cost: about 30 minutes, no workaround yet. macOS 27.0.1.

### Lean in

- `app.json` already had a `host.macos` window, from `exact new`.
- The shared `modules/apple` folder with `#if os(macOS)` branches kept the native code in one
  place. The whole module (four files changed) compiled for the Mac on the first build.
- The list-and-detail split came for free: on the Mac the inbox and the open chat show side
  by side at 900 points, with the same contract as the phone's stack.
- A native alert (`NSAlert`) and a native color panel worked from the drive with no extra
  work.
