### Rough
- A second git worktree of the app at another folder depth did not build: `ios --sim` refused with "[patch.crates-io] must name exact2's vendored accesskit_windows, ..." (known: finding "an app checkout at another depth"). `bun exact.mjs update` rewrote `Cargo.toml`, `apple/Cargo.toml` and `web/Cargo.toml`, but not `package.json`'s `file:` paths to the framework's packages, so `bun install --frozen-lockfile` then failed with `Could not find folder "file:../../../exact/exact2/packages/clipboard"`. I edited `package.json` by hand and kept all of these files out of git (`git update-index --skip-worktree`). About 5 minutes. What would have helped: `update` (or `EXACT2`) also covering `package.json`'s framework packages, or the refusal naming every file that holds a framework path.
- No remote push: no send answers the APNs token, the host's app delegate has no token callbacks, and the build signs `aps-environment` only for a pushed Live Activity. Without it, iOS answered "no valid aps-environment entitlement string found for application", on the Simulator too. The native module adds the two callbacks to the host's app delegate class at run time (`class_addMethod`); the archive check would refuse `registerForRemoteNotifications` for TestFlight. About 30 minutes. What would have helped: LLP 1133.004 section 9 built (a token source and a grant that signs `aps-environment`).
- No app-defined extension, and no declared entitlements (App Group, Keychain group, `aps-environment`). A script compiles the notification extension with the share extension's flags (`appexArgs`) and puts it in `PlugIns/`. On the Simulator the app's entitlements live in the binary's `__TEXT,__entitlements` section; `segedit -replace` refused it ("requires relocation"), and the section is exactly the size of Exact's plist (462 bytes), so the script writes a compact XML plist padded with spaces, leaving out Exact's second, legacy Keychain group to fit, then signs ad hoc. About 90 minutes. What would have helped: an extension declared in `app.json`, declared entitlements, or a hook after bundling and before signing.
- The extension carries its own copy of the vendor library (73 MB), since the native module's code is linked into the framework's modules dylib with its runtime. Not measured as time; a size cost.
- A drive installs the framework's build: it keeps the extension only because the script patched that build in place; a rebuild drops it until the script runs again.
